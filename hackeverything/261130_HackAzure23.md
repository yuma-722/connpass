# Hack Azure #23

**Microsoft Ignite・GitHub Universe・FabCon Recap！ Geek 4名のお気に入りデモ大会**

今回の Hack Azure では、Microsoft Ignite、GitHub Universe、FabCon の話題を振り返ります。今回はいつもと少し趣向を変えて、Geek 4名がそれぞれ気になった技術やアップデートを持ち寄り、デモを交えて紹介します！

いつもより長めの2時間で、それぞれの「これが面白い！」をたっぷりお届けします。イベントの発表をキャッチアップしたい方も、気になる技術が実際に動くところを見たい方も、ぜひご参加ください。

質問や感想は、X（旧Twitter）で [#hackazure](https://x.com/intent/post?hashtags=hackazure) のタグをつけて投稿ください！
