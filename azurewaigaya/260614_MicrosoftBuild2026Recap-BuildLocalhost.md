Microsoft Build 2026 の熱気をそのままに、**Build //localhost** の枠組みで Recap イベントを Azureわいがや会 主催で開催します！

Keynote をみんなで視聴 → 気になったキーワードをその場で集めて、野生の Microsoft MVP や詳しい参加者がリアルタイムでわいがや解説・検証・デモ with DJ！

# Build //localhost とは

Build //localhost は、Microsoft Build の技術コンテンツを地域コミュニティに展開する取り組みです。2026年6月9日〜26日の期間中、世界各地でMVPおよびコミュニティリーダーが対面型の技術イベントを開催し、Microsoft Build の最新コンテンツを活用したハンズオン体験を提供します。

# 参加にあたって

- 現地参加のみ

# 本編の説明

## 概要

「Build 2026、何が熱かったの？」
「発表されたあのキーワード、結局どういうこと？」
「気になったところをその場で誰かに聞きたい・触ってみたい」

そんな方、Welcome！

**Keynote 視聴 → みんなで気になったワードを書き出し → MVPや詳しい誰かがその場で解説・検証・デモ** という流れでわいがやしましょう

## Keynote 視聴について

視聴するのはこちら（90分）：

[Microsoft Build 2026 Keynote](https://build.microsoft.com/en-US/sessions/KEY01)

視聴中、気になったワード・発表・サービス名などを共有ボード（当日案内します）にどんどん書き込んでください。これが後半の深掘りタイムの「ネタ」になります。

## キーワード深掘りわいがやタイム

集まったキーワードを、カテゴリの近い MVP や詳しい参加者がその場で拾ってわかれば解説、わからなければわいがやみんなで検証します。

## 禁止事項

- 勧誘活動
- 飲食目的の参加
- 「わからない」を否定する言動
- 誰かが不快になる言動
- その他、主催者が不適切と判断する行為

## 推奨事項

- わからないことを質問する
- できたこと・詰まったことを共有する
- 気になったワードをどんどん書き出す
- とにかくわいがや楽しむ
