# GitHubの中の人セッションあり！GitHub Universe 2026 Recap & Badge Hack Party!

[GitHub Vibe Riders](https://www.youtube.com/@GitHubVibeRiders) で、**GitHub Universe 2026 Recap** を開催します！

GitHub Universe 2026の更新情報をキャッチアップしながら、現地参加した主催者 Maki（[@yuma_prog](https://x.com/yuma_prog)）から、現地で聞いた話や会場の様子もお届けします。さらに、**現地でもらってきたスワッグ・ステッカーも配布します！**

 <img src="https://pbs.twimg.com/media/HWSSkUNbMAAUHty?format=jpg&name=large" width="600">


更新情報を聞くだけでなく、「この機能実際どう？」など、参加者同士で意見をシェアしてわいがやしましょう！

さらに！スペシャルゲストとして、**GitHub Learn Teamの[Christopher Blake](https://www.linkedin.com/in/chriswblake/)氏による特別セッション**もあります。現地での最新情報に加えて、日本で直接話を聞けるとても貴重な機会です。

そして、最後には**GitHub Universe名物の「Badge Hack」**も体験していただきます。今年のバッジは加速度センサー・ジャイロ・タッチコントローラー・バッジ間の通信機能付きなのでハックしがいしかありません。[シミュレータ](https://badger.github.io/simulator/)があるので、気軽に動確できますし、実際にバッジに書き込むチャンスも…。

[GitHub公式のバッジ動画](https://x.com/github/status/2114145673033691289/video/1)



普段現地参加勢しかできないハック体験を一緒に体験してみましょう！

参考：[Badgeハードウェア情報](https://github.com/badger/home/blob/main/hardware/README.md)
